# Hot Wash (Vercel + Supabase): work in progress

Paused scaffold. It was started for the original six-column kanban design and has not been
updated for the three-part hot wash page in `../prototype/hotwash.html`, which is now the spec.

What exists:
- `supabase/migrations/` schema with row level security and realtime (boards, cards, votes, comments, profiles, surveys)
- `supabase/seed.sql` generated by `scripts/generate-seed.mjs` (from the older kanban seed format; needs updating)
- Supabase auth (magic link), `src/proxy.ts` session refresh, board and login pages
- Not built: the board client component, Word export route

Not yet built or tested. Do not deploy.
